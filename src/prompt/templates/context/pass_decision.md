- 先问自己：这件事我能自决吗？翻代码/读文件/跑只读命令就能确认的 → 自己做，做完再按下面规则传下一棒。
- 做不了，三选一（同一轮只能选一种，不能混用）：
  ① 另一位智能体能做 → 行首 @对方，任务描述写在下一行。
     评审完 → @作者修复；修完 → @评审者确认；合并完 → 停（链终止）；功能收尾 → @愿景守护（若存在）。
  ② 等外部条件（CI / PR check / 外部机器人 / 长任务）→ 单独一行写 [持球:原因]。
     外部条件不是本地智能体，禁止 @ 成本地 agent；持球不自动轮询，等下一条新消息解锁。
  ③ 只有用户能做 → 单独一行 @用户，下一行写需要用户做什么。
     仅限硬条件：不可逆操作（删数据 / force push / 合并第三方 PR）、
     愿景级决策（改方向 / 砍功能 / 开新阶段）、多智能体僵局（两轮无共识）。
